Console에 로그인하고 Console 에이전트를 조직과 연결하십시오. 로그인 방법은 Console 사용 모드에 따라 다릅니다. 표준 모드로 Console을 사용하는 경우 SaaS 웹 사이트를 통해 로그인합니다. 제한 모드 또는 비공개 모드로 Console을 사용하는 경우 Console 에이전트 호스트에서 로컬로 로그인합니다.

.단계
. 웹 브라우저를 열고 콘솔 에이전트 호스트 URL을 입력하십시오.
+
콘솔 호스트 URL은 호스트의 구성에 따라 로컬 호스트, 사설 IP 주소 또는 공용 IP 주소가 될 수 있습니다. 예를 들어 콘솔 에이전트가 공용 IP 주소 없이 퍼블릭 클라우드에 있는 경우 콘솔 에이전트 호스트에 연결된 호스트의 사설 IP 주소를 입력해야 합니다.

. 회원가입 또는 로그인하세요.
. 로그인 후 Console을 설정합니다.
+
.. 콘솔 에이전트와 연결할 콘솔 조직을 지정합니다.
.. 시스템 이름을 입력합니다.
.. *보안 환경에서 실행 중이십니까?* 항목에서 제한된 모드를 비활성화 상태로 유지하십시오.
+
콘솔 에이전트가 온프레미스에 설치된 경우 제한된 모드는 지원되지 않습니다.

.. *시작하기*를 선택합니다.
