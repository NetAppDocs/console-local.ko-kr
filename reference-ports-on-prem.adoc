= NetApp Console 로컬 배포를 위한 인바운드 포트
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
NetApp Console 로컬 배포 OVA는 자체 내부 방화벽을 관리합니다. 환경에서 VM에 외부 방화벽 정책이 적용되는 경우 관리 호스트에서 다음 인바운드 포트에 접근할 수 있는지 확인하십시오.

[cols="10,10,80"]
|===
| 포트 | 프로토콜 | 목적 


| 22 | TCP | 원격 유지 관리 및 진단 셸 액세스를 위한 SSH 


| 123 | UDP | 시간 동기화를 위한 NTP 


| 2379 | TCP | RKE2 컨트롤 플레인 etcd 클라이언트 트래픽을 위한 etcd 클라이언트 API 


| 2380 | TCP | etcd 멤버 간 복제를 위한 etcd 피어 포트 


| 6443 | TCP | kubectl 및 RKE2 API 접근을 위한 Kubernetes API 서버 


| 8472 | UDP | RKE2 노드 간 포드 간 트래픽을 위한 Canal/Flannel VXLAN 오버레이 


| 9091 | TCP | Calico Felix CNI 상태 및 메트릭을 위한 메트릭 엔드포인트 


| 9100 | TCP | 호스트 메트릭 스크래핑을 위한 Prometheus node_exporter 


| 9345 | TCP | RKE2 슈퍼바이저 및 서버 등록 엔드포인트 


| 10250 | TCP | 메트릭 서버 및 kube-apiserver에서 kubelet으로의 Kubelet API 
|===
