= LLM을 연결하고 NetApp Console 로컬 배포에서 NetApp Console 어시스턴트를 활성화합니다
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
지원되는 LLM 엔드포인트를 연결하여 NetApp Console 로컬 배포 사용자가 관리되는 자연어 기반 스토리지 지침 및 작업을 사용할 수 있도록 합니다.


NOTE: LLM을 콘솔 어시스턴트에 연결하여 AI 기능을 활성화하는 방법에 대한 이 문서는 기술 미리 보기로 제공됩니다. 이 미리 보기 제공을 통해 NetApp은 정식 출시 전에 제공 세부 정보, 콘텐츠 및 일정을 수정할 권리를 보유합니다.

.필수 액세스 역할
최고 관리자 또는 조직 관리자. link:reference-iam-predefined-roles.html["액세스 역할에 대해 알아보기"].

설정이 완료되면 사용자는 대시보드에서 Console 어시스턴트를 열고 액세스 모드를 선택합니다.

* 읽기 전용 모드에서는 어시스턴트가 변경 사항을 적용하지 않고 질문에 답변하고 안내를 제공합니다.
* 읽기/쓰기 모드에서 어시스턴트는 스토리지 인프라에 대해 작업을 수행할 수 있습니다. 각 변경 전에 검토 및 확인을 위한 세부 정보를 표시합니다. 볼륨 생성 등 비동기 작업의 경우, 사용자가 어시스턴트에서 확인할 수 있는 작업을 생성합니다.


LLM을 연결하려면 공급자 경로를 선택하고 엔드포인트 세부 정보와 API 키를 입력한 다음 *관리 > AI 툴*에서 모델을 선택하십시오. 어시스턴트 작업은 스토리지 정책 및 역할 기반 액세스 제어 범위 내에서 유지됩니다.



[[before-you-begin]]
== 시작하기 전에

콘솔 도우미가 조직에 구성된 거버넌스 경계 내에서 작동할 수 있도록 공급자 자격 증명과 엔드포인트 액세스 권한을 준비하십시오.

* 릴리스 및 엔드포인트에서 지원하는 제공업체 유형 결정: OpenAI, OpenAI 호환 또는 Anthropic.
* 선택한 공급자 경로에 대한 유효한 API 키입니다.
* 제공업체 경로의 엔드포인트 URL입니다.
* 필요한 경우 LLM 공급자 계정의 사용자 이름 또는 ID입니다.
* 콘솔 로컬 배포에서 선택한 엔드포인트까지의 네트워크 액세스.


link:reference-llm-supported-models.html["NetApp Console 로컬 배포에서 지원되는 LLM 제공업체 및 모델에 대해 알아보십시오"].



[[connect-an-llm-to-netapp-console-local-deployment]]
== LLM을 NetApp Console 로컬 배포에 연결합니다

검증된 공급자 구성을 통해 어시스턴트 기능을 활성화하는 동시에 엔드포인트 자격 증명에 대한 관리 제어를 유지합니다.

.단계
. NetApp Console 로컬 배포에 로그인합니다.
. *관리 > AI 툴*을 선택합니다.
. 메뉴를 선택한 다음 *편집*을 선택합니다.
. *제공자 유형*에서 제공자 유형을 선택하십시오.
+
link:concept-llm-integration.html["NetApp Console 로컬 배포에서 LLM 통합에 대해 알아보세요."].

. 공급자 엔드포인트를 입력하라는 메시지가 표시되면 선택한 공급자 경로의 엔드포인트 URL을 입력하십시오.
. *사용자 이름* 필드에 공급자 경로에서 요구하는 경우 사용자 이름 또는 SSO ID를 입력하십시오.
. *API 키* 필드에 선택한 공급자 경로의 API 키를 붙여넣습니다.
. 목록에서 모델을 선택합니다.
. 구성을 검토한 다음 *저장*을 선택합니다.
+
구성을 저장하기 전에 공급자 유형, 엔드포인트 URL, API 키 및 선택한 모델을 검토하십시오.





[[verify-that-llm-integration-works]]
== LLM 통합이 제대로 작동하는지 확인하십시오.

사용자가 구성된 통합 기능을 통해 관리되는 작업을 안정적으로 수행할 수 있도록 어시스턴트 가용성 및 승인 동작을 확인하십시오.

.단계
. 콘솔 도우미를 읽기 전용 모드로 열고 기본 쿼리를 실행합니다.
. *콘솔 도우미*를 *읽기/쓰기* 모드로 열고 스토리지 변경 작업 실행 전에 사용자 확인이 필요한지 확인하십시오.
. 액션 워크플로가 필요한 사용자가 필요한 역할 기반 액세스 제어 권한을 가지고 있는지 확인하십시오.


유효성 검사가 완료되면 사용자는 대시보드에서 Console assistant를 열고 일반 언어로 작업을 설명할 수 있습니다. link:task-console-asst-use.html["NetApp Console 어시스턴트 사용에 대해 알아보기"].



[[protect-credentials-and-monitor-llm-usage]]
== 자격 증명을 보호하고 LLM 사용을 모니터링합니다.

LLM 자격 증명을 보호하고 공급자 활동을 모니터링하여 통합 기능의 무단 사용을 줄이고 조직 거버넌스를 지원합니다.

* 가능하면 콘솔 로컬 배포 통합을 위해 전용 API 키를 사용하십시오.
* 조직 정책에 따라 API 키를 교체하십시오.
* 조직의 거버넌스 요구 사항에 따라 공급자 측 API 사용량 및 알림을 모니터링하십시오.
