.단계
. *관리 > *자격 증명*을 선택합니다.
. *조직 자격 증명*을 선택합니다.
. Console 에이전트와 연결된 자격 증명 세트의 작업 메뉴를 선택한 다음 *Configure Subscription*을 선택합니다. +새 스크린샷 필요(TS) image:screenshot_gcp_add_subscription.png["기존 자격 증명 세트에 대한 작업 메뉴의 스크린샷."]
. 선택한 자격 증명으로 기존 구독을 구성하려면 드롭다운 목록에서 Google Cloud 프로젝트와 구독을 선택한 다음 *구성*을 선택합니다.
+
image:screenshot_gcp_associate.gif["Google Cloud 자격 증명에 대해 선택된 Google Cloud 프로젝트 및 구독의 스크린샷."]

. 아직 구독이 없는 경우 *구독 추가 > 계속*을 선택하고 Google Cloud Marketplace의 단계를 따르십시오.
+

NOTE: 다음 단계를 완료하기 전에 Google Cloud 계정에 청구 관리자 권한이 있고 NetApp Console에 로그인되어 있는지 확인하십시오.

+
..  https://console.cloud.google.com/marketplace/product/netapp-cloudmanager/cloud-manager["Google Cloud Marketplace의 NetApp Intelligent Services 페이지"^]로 리디렉션된 후 상단 탐색 메뉴에서 올바른 프로젝트가 선택되어 있는지 확인하십시오.
+
image:screenshot_gcp_cvo_marketplace.png["Google Cloud의 Cloud Volumes ONTAP 마켓플레이스 페이지 스크린샷입니다."]

.. *구독*을 선택합니다.
.. 적절한 결제 계정을 선택하고 이용 약관에 동의하십시오.
.. *구독*을 선택합니다.
+
이 단계에서는 전송 요청을 NetApp에 보냅니다.

.. 팝업 대화 상자에서 *Register with NetApp, Inc.*를 선택합니다.
+
Google Cloud 구독을 Console 조직 또는 계정에 연결하려면 이 단계를 완료해야 합니다. 구독 연결 프로세스는 이 페이지에서 리디렉션된 후 Console에 로그인해야 완료됩니다.

+
image:screenshot_gcp_marketplace_register.png["등록 팝업창의 스크린샷입니다."]

.. *구독 할당* 페이지의 단계를 완료합니다.
+

NOTE: 조직 구성원 중 누군가가 이미 동일한 결제 계정으로 마켓플레이스 구독을 보유하고 있는 경우, 대신 https://bluexp.netapp.com/ontap-cloud?x-gcp-marketplace-token=["NetApp Console 내의 Cloud Volumes ONTAP 페이지"^]으로 리디렉션됩니다. 예상치 못한 상황이라면 NetApp 영업팀에 문의하십시오. Google은 Google 결제 계정당 하나의 구독만 허용합니다.

+
*** 이 구독을 연결할 콘솔 조직 또는 계정을 선택하십시오.
*** *기존 구독 교체* 필드에서 하나의 조직 또는 계정에 대한 기존 구독을 이 새 구독으로 자동으로 교체할지 여부를 선택합니다.
+
콘솔은 조직 또는 계정의 모든 자격 증명에 대한 기존 구독을 이 새 구독으로 대체합니다. 자격 증명 세트가 이전에 구독과 연결된 적이 없는 경우, 이 새 구독은 해당 자격 증명과 연결되지 않습니다.

+
다른 모든 조직 또는 계정의 경우, 위의 단계를 반복하여 구독을 수동으로 연결해야 합니다.

*** *저장*을 선택합니다.
