[IMPORTANT]
====
* 새로운 에이전트를 배포할 때 NetApp은(는) 다음 엔드포인트를 확인합니다. link:reference-networking-saas-console.html["여기에 나열됨"^] 이전 업그레이드에 사용된 엔드포인트를 사용하는 경우 이 구성 검사가 오류와 함께 실패합니다. link:reference-networking-saas-console-previous.html["여기에 나열됨"] NetApp은(는) 가능한 한 빨리 방화벽 규칙을 업데이트하여 현재 엔드포인트에 대한 액세스를 허용하고 이전 엔드포인트에 대한 액세스를 차단할 것을 권장합니다. link:reference-networking-saas-console-previous.html#update-endpoint-list["네트워크를 업데이트하는 방법을 알아보십시오."]
* 방화벽의 엔드포인트를 업데이트하더라도 기존 에이전트는 계속 작동합니다.
