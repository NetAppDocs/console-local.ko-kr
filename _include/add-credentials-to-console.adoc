콘솔 에이전트를 설치하고 설정한 후에는 클라우드 자격 증명을 추가하여 콘솔 에이전트가 AWS 또는 Azure에서 작업을 수행하는 데 필요한 권한을 갖도록 하십시오.

[role="tabbed-block"]
====
.AWS
--
.시작하기 전에
방금 AWS 자격 증명을 생성했다면 사용 가능해지기까지 몇 분 정도 걸릴 수 있습니다. Console에 자격 증명을 추가하기 전에 잠시 기다려 주십시오.

.단계
. *관리 > 자격 증명*을 선택합니다.
. *조직 자격 증명*을 선택합니다.
. *자격 증명 추가*를 선택하고 마법사의 단계를 따릅니다.
+
.. *자격 증명 위치*: *Amazon Web Services > 에이전트*를 선택합니다.
.. *자격 증명 정의*: AWS 액세스 키와 비밀 키를 입력하십시오.
.. *마켓플레이스 구독*: 지금 구독하거나 기존 구독을 선택하여 이 자격 증명과 마켓플레이스 구독을 연결합니다.
.. *검토*: 새 자격 증명에 대한 세부 정보를 확인하고 *추가*를 선택합니다.




이제  https://console.netapp.com["NetApp Console"^]로 이동하여 Console 에이전트를 사용할 수 있습니다.

--
.Azure
--
.시작하기 전에
방금 Azure 자격 증명을 생성한 경우 사용 가능해지기까지 몇 분 정도 걸릴 수 있습니다. Console 에이전트에 자격 증명을 추가하기 전에 몇 분 정도 기다리십시오.

.단계
. *관리 > 자격 증명*을 선택합니다.
. *자격 증명 추가*를 선택하고 마법사의 단계를 따릅니다.
+
.. *자격 증명 위치*: *Microsoft Azure > 에이전트*를 선택합니다.
.. *자격 증명 정의*: 필요한 권한을 부여하는 Microsoft Entra 서비스 주체에 대한 정보를 입력하십시오.
+
*** 애플리케이션(클라이언트) ID
*** 디렉터리(테넌트) ID
*** Client Secret


.. *마켓플레이스 구독*: 지금 구독하거나 기존 구독을 선택하여 이 자격 증명과 마켓플레이스 구독을 연결합니다.
.. *검토*: 새 자격 증명에 대한 세부 정보를 확인하고 *추가*를 선택합니다.




.결과
이제 콘솔 에이전트는 사용자를 대신하여 Azure에서 작업을 수행하는 데 필요한 권한을 갖습니다. 이제  https://console.netapp.com["NetApp Console"^]으로 이동하여 콘솔 에이전트를 사용할 수 있습니다.
