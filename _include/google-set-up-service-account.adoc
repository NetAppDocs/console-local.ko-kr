콘솔 에이전트 VM 인스턴스에 사용할 서비스 계정에 역할을 생성하고 적용합니다.

.단계
. Google Cloud에서 사용자 지정 역할을 생성합니다.
+
.. link:reference-permissions-gcp.html["Google Cloud용 콘솔 에이전트 정책"]에 정의된 권한을 포함하는 YAML 파일을 생성합니다.
.. Google Cloud에서 클라우드 셸을 활성화합니다.
.. 콘솔 에이전트에 필요한 권한이 포함된 YAML 파일을 업로드합니다.
..  `gcloud iam roles create` 명령을 사용하여 사용자 지정 역할을 생성합니다.
+
다음 예제는 프로젝트 수준에서 "connector"라는 이름의 역할을 생성합니다.

+
[source, gcloud]
----
gcloud iam roles create connector --project=myproject --file=connector.yaml
----
+
https://cloud.google.com/iam/docs/creating-custom-roles#iam-custom-roles-create-gcloud["Google Cloud 문서: 사용자 지정 역할 생성 및 관리"^]



. Google Cloud에서 서비스 계정을 생성합니다.
+
.. IAM 및 관리 서비스에서 *서비스 계정 > 서비스 계정 생성*을 선택합니다.
.. 서비스 계정 정보를 입력하고 *생성 및 계속*을 선택합니다.
.. 방금 생성한 역할을 선택합니다.
.. 나머지 단계를 완료하여 역할을 생성합니다.
+
https://cloud.google.com/iam/docs/creating-managing-service-accounts#creating_a_service_account["Google Cloud 문서: 서비스 계정 생성"^]





.결과
이제 콘솔 에이전트 VM 인스턴스에 할당할 수 있는 서비스 계정이 생성되었습니다.
