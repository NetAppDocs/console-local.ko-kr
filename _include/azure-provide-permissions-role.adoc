Azure 포털로 이동하여 하나 이상의 구독에 대해 Console 에이전트 가상 머신에 Azure 사용자 지정 역할을 할당합니다.

.단계
. Azure 포털에서 *구독* 서비스를 열고 구독을 선택합니다.
+
*구독* 서비스에서 역할을 할당하는 것이 중요합니다. 구독 수준에서 역할 할당 범위를 지정하기 때문입니다. _범위_는 액세스가 적용되는 리소스 집합을 정의합니다. 다른 수준(예: 가상 머신 수준)에서 범위를 지정하면 NetApp Console에서 작업을 완료할 수 있는 기능에 영향을 미칩니다.

+
https://learn.microsoft.com/en-us/azure/role-based-access-control/scope-overview["Microsoft Azure 설명서: Azure RBAC의 범위 이해하기"^]

. *액세스 제어(IAM)* > *추가* > *역할 할당 추가* 를 선택합니다.
. *역할* 탭에서 *Console Operator* 역할을 선택하고 *다음*을 선택합니다.
+

NOTE: Console Operator는 정책에 기본적으로 제공되는 이름입니다. 역할에 다른 이름을 선택한 경우 해당 이름을 선택하십시오.

. *Members* 탭에서 다음 단계를 완료합니다.
+
.. *관리되는 ID*에 액세스 권한을 할당합니다.
.. *멤버 선택*을 선택하고 콘솔 에이전트 가상 머신이 생성된 구독을 선택한 다음, *관리 ID*에서 *가상 머신*을 선택하고 콘솔 에이전트 가상 머신을 선택합니다.
.. *선택*을 선택합니다.
.. *다음*을 선택하십시오.
.. *검토 + 할당*을 선택합니다.
.. 다른 Azure 구독의 리소스를 관리하려면 해당 구독으로 전환한 다음 이러한 단계를 반복합니다.
